# Pagination Documentation Site

A beautiful, modern documentation site for the `@lucasmogari/pagination` library.

## Features

- 📱 Fully responsive design
- ⚡ Fast static site with Vite
- 🎨 Modern, clean UI
- 📚 Comprehensive API documentation
- 💡 Interactive examples and demos
- 🔍 Easy navigation

## Getting Started

### Installation

Install dependencies:

```bash
npm install
# or
pnpm install
# or
yarn install
```

### Development

Start the development server:

```bash
npm run dev
```

The site will open at `http://localhost:3000` by default.

### Building

Build the static site for production:

```bash
npm run build
```

The output will be in the `dist` directory.

### Preview

Preview the production build locally:

```bash
npm run preview
```
