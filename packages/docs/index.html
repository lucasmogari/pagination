Pagination Made Simple

A lightweight, framework-agnostic JavaScript library for generating pagination items with powerful customization options.

Get Started GitHub

Features

🎯 Framework Agnostic

Works with any JavaScript framework or vanilla JS. Use it with React, Vue, Angular, or anything else.

⚙️ Highly Configurable

Customize every aspect of your pagination: items per page, max items to show, gaps, arrows, first/last buttons.

📦 Lightweight

Small bundle size with zero dependencies. Perfect for any project.

🔄 Flexible Output

Get detailed pagination items with types for numbers, gaps, arrows, and boundary controls.

Installation

Install the package using your preferred package manager:

npm install @lucasmogari/pagination
yarn add @lucasmogari/pagination
pnpm add @lucasmogari/pagination

Basic Usage

Simple Example

Import the pagination function and use it with a callback to handle pagination items: 

import pagination from '@lucasmogari/pagination';

const items = pagination(
    1,           // current page
    100,         // total items
    (item) => item,
    {
      itemsPerPage: 10,
      maxPageItems: 7,
      numbers: true,
      arrows: true,
      first: true,
      last: true,
      gapValues: false,
    }
  );

console.log(items);
// [
//   { type: 'first', page: 1, current: true },
//   { type: 'previous' },
//   { type: 'page', page: 1, current: true },
//   { type: 'page', page: 2 },
//   ...
// ]

React Example

Use with React to create a pagination component:

import { useState } from 'react';
import pagination from '@lucasmogari/pagination';

export function Pagination({ totalItems }) {
  const [currentPage, setCurrentPage] = useState(1);
  
  const items = pagination(
    currentPage,
    totalItems,
    (item) => item,
    {
      itemsPerPage: 10,
      maxPageItems: 7,
      numbers: true,
      arrows: true,
      first: true,
      last: true,
    });

  return (
    <nav>
      {items.map((item, index) => (
        <button
          key={index}
          onClick={() => item.page && setCurrentPage(item.page)}
          disabled={!item.page}
          className={item.current ? 'active' : ''}
        >
          {item.type === 'gap' ? '...' : item.page || (
            item.type === 'previous' ? '←' : '→'
          )}
        </button>
      ))}
    </nav>
  );
}

API Documentation

pagination()

Main function to generate pagination items.

Parameters

Parameter Type Description
page number The current page number (1-indexed)
totalItems number Total number of items to paginate
callback function Callback function that receives each pagination item
options object Configuration options (optional)

Options

Option Type Default Description
itemsPerPage number 1 Number of items displayed per page
maxPageItems number 1 Maximum number of page items to display
numbers boolean false Show page number items
arrows boolean false Show previous/next arrows
first boolean false Show first page button
last boolean false Show last page button
gapValues boolean false Include page numbers in gap items

PageItem Type

The callback receives one of the following page item types:

type PageItem =
  | { type: 'page'; page: number; current?: boolean }
  | { type: 'previous'; page?: number }
  | { type: 'next'; page?: number }
  | { type: 'gap'; pages?: number[] }
  | { type: 'first'; page: number; current?: boolean }
  | { type: 'last'; page: number; current?: boolean };
page

A regular page number. If current is true, it's the current page.

previous

Previous page button. page is set if not on first page.

next

Next page button. page is set if not on last page.

gap

Gap between page items (shows "..."). pages array available if gapValues: true.

first

First page button. If current is true, you're on the first page.

last

Last page button. If current is true, you're on the last page.

Examples

Minimal Pagination

Show only number buttons with arrows:

pagination(5, 100, callback, {
  itemsPerPage: 10,
  maxPageItems: 5,
  numbers: true,
  arrows: true,
});

Full-Featured Pagination

All features enabled:

pagination(5, 100, callback, {
  itemsPerPage: 10,
  maxPageItems: 7,
  numbers: true,
  arrows: true,
  first: true,
  last: true,
  gapValues: true,
});
